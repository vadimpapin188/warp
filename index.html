Превращай HTML, CSS и JS в быстрые Windows-приложения

Warp — это суперлёгкий рантайм. Без сборщиков, без сложного Node.js и без гигабайтов лишнего кода. Просто запусти `.exe` рядом с сайтом.

Документация

🚀 Никакой сборки

Не нужно компилировать проект. Просто переименуй `core.exe` и положи в папку со своими HTML-файлами.

🔔 Системный трей

Встроенная поддержка создания иконки и меню в трее Windows прямо из вашего JavaScript.

⚡ Быстрый JS API

Управляй заголовком, размером окна и его состоянием на лету с помощью понятного `api.js`.

Пример использования api.js
await set_window_name("My app");
