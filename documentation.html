Работа с окном и системным треем

В этом разделе описаны функции Warp API для управления окном приложения и иконками в трее.

1. Подключение Warp API

Перед использованием функций подключите файл warp_api.js в вашем HTML-файле перед основным скриптом:

HTML
<script src="warp_api.js"></script>
<script src="app.js"></script>

2. Функции API

set_window_name(name)

Устанавливает заголовок (название) окна приложения.

Пример использования
await set_window_name("Мое приложение");

set_size(w, h)

Задает ширину (w) и высоту (h) окна в пикселях.

Пример использования
// Установит размер окна 800 на 600 пикселей
await set_size(800, 600);

create_stray_icon(name, des, icon_path)

Создает иконку приложения в системном трее (возле часов).

Параметры:

  • name — название приложения в трее
  • des — всплывающее описание при наведении
  • icon_path — путь к файлу иконки (.ico или .png)
Пример использования
await create_stray_icon("Warp App", "Мое приложение работает в фоне", "icon.png");

create_stray_menu(name_item)

Добавляет пункт меню для иконки в системном трее.

Пример использования
await create_stray_menu("Выход");

developer_mode()

Включает режим разработчика и открывает инструменты отладки (DevTools / Консоль).

Пример использования
await developer_mode();
